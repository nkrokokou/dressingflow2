# DressingFlow 2.0 - Plateforme de Mode Collaborative

Une plateforme de mode innovante combinant les fonctionnalités de marketplace et d'e-commerce social, inspirée de Shein, Vinted et Bagisto.

## 🚀 Fonctionnalités Principales

### Pour les Clients
- 📱 Interface utilisateur moderne et réactive
- 🛍️ Découverte de produits personnalisée
- 🛒 Panier unifié multi-vendeurs
- 💳 Paiements sécurisés
- 📱 Application mobile (à venir)

### Pour les Vendeurs
- 🏪 Boutique personnalisable
- 📊 Tableau de bord de vente
- 📦 Gestion des stocks et commandes
- 💬 Messagerie client
- 📈 Analyses de performance

### Pour l'Administrateur
- 👥 Gestion des utilisateurs et rôles
- 🛡️ Modération du contenu
- 📊 Tableaux de bord avancés
- ⚙️ Configuration de la plateforme

## 🛠️ Technologies

### Backend
- Node.js avec NestJS
- PostgreSQL avec TypeORM
- Redis pour le cache
- Elasticsearch pour la recherche
- JWT pour l'authentification

### Frontend
- Next.js 14 avec App Router
- TypeScript
- Tailwind CSS
- Shadcn/ui
- Zustand pour la gestion d'état

## 🚀 Démarrage Rapide

### Prérequis
- Node.js 18+
- PostgreSQL 14+
- pnpm

### Installation
1. Cloner le dépôt
2. Installer les dépendances :
   ```bash
   pnpm install
   ```
3. Configurer les variables d'environnement
4. Lancer le développement :
   ```bash
   pnpm dev
   ```
